# __PROJECT_NAME__ — WorldForge project

Roblox game generated by WorldForge AI: **roblox-ts** (TypeScript → Luau) + **Rojo**. Agents (Claude Code,
Codex, Gemini…) work in this folder; the WorldForge desktop app regenerates the world, syncs to Studio and
publishes through Open Cloud.

## Ground rules

- All gameplay code is TypeScript under `src/`. Never write Luau by hand; `npx rbxtsc` compiles to `out/`.
- `assets/world/WorldBake.json` is generated — never edit it. The world comes from
  `worlds/main/world.spec.json` (WorldSpec) + `worlds/main/style.bible.json` (StyleBible).
- `src/shared/config.ts`, `catalog.ts`, `animations.ts`, `audio.ts`, `npcs.ts`, `quests.ts`, `recipes.ts`
  are generated from `design/game.spec.json`; edit the GameSpec (or the TS, knowing a regeneration overwrites it).
- Server-authoritative: currency, damage, purchases and progression live in `src/systems/*` (server).
  A LocalScript may only *ask* through the typed remotes in `src/shared/net.ts`.
- Credentials never enter this repo: API keys and Open Cloud tokens stay in the WorldForge app (OS keychain).
- Validate with `npx rbxtsc` before finishing any TypeScript change.

## Skills (`.claude/skills/`)

| Skill | Use it when |
|---|---|
| `worldforge-world` | changing the map: WorldSpec fields, terrain features (mountains, valley, **island / coast**), biomes, rivers, landmarks, settlements, walls, roads, weather, layout archetypes |
| `worldforge-gameplay` | adding or changing gameplay systems, remotes, zones, PlayerData, enemies, rounds… |
| `worldforge-ui` | HUD, shop, menus, mobile layout, theme from the StyleBible |
| `worldforge-assets` | catalog items, gamepasses / dev products, animations, audio manifest, toolbox & hero meshes |
| `worldforge-qa` | compiler / runtime errors, Studio play-test checklist per genre, `qa/report.json` |
| `worldforge-publish` | Rojo build, Open Cloud publish, place configuration, monetization checklist |
| `roblox-ts-pitfalls` | any TypeScript that must compile with roblox-ts (reserved names, `.size()`, `pairs`, …) |

User-level skills, when installed in `~/.claude/skills`, are complementary: `roblox-best-practices` (Luau
standards), `roblox-opsec` (exploit-surface audit before publishing), `roblox-game` (genre design notes),
`ui-ux-pro-max` / `design` (visual polish).

## Layout

```
src/server/main.server.ts   bootstrap: build world → start systems
src/client/main.client.ts   HUD, shop, hotkeys, weather layer, client effects
src/shared/                 config, net (remotes), zones, catalog, quests, recipes, world decode
src/systems/                PlayerData, Survival, Collectibles, Shop, Npcs, Audio, Combat, Enemies,
                            Checkpoints, Progression, Tycoon, Simulator, Rounds, Racing, TowerDefense,
                            Economy (farming/mining/crafting/pets/housing/trading), Modes, Doors
src/ui/                     kit (Window + widgets), Hud, ShopUi, Inventory, Quests, Crafting,
                            Leaderboard, Teams, RoundStatus, Settings, Minimap, Menu (Instances, no framework)
src/world/                  WorldBuilder (terrain voxels, prefabs, lighting, zones, spawn)
worlds/main/                world.spec.json, style.bible.json
design/                     game.spec.json, asset & audio manifests
qa/                         report.json, vision.json
```
