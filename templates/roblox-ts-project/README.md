# __PROJECT_NAME__

Generated by **WorldForge AI**. This is a standard [roblox-ts](https://roblox-ts.com) + [Rojo](https://rojo.space) project.

```
npm install          # once
npm run build        # rbxtsc: TypeScript → Luau (out/)
npm run rbxl         # rojo build → build/*.rbxl (open in Roblox Studio)
npm run serve        # rojo serve → connect the Rojo plugin in Studio for live sync
```

## Layout

- `src/server` — server bootstrap (`main.server.ts`)
- `src/client` — client bootstrap (`main.client.ts`)
- `src/shared` — shared modules (config, remotes, world decoding, prefab factory)
- `src/world` — runtime world builder (terrain voxels, prefabs, lighting, spawn)
- `src/systems` — gameplay systems (player data, survival, collectibles…)
- `src/ui` — Roblox UI built from Instances
- `assets/world/WorldBake.json` — the baked world (terrain heightmap + prefab library + placements). Regenerated by WorldForge; do not edit by hand.
- `worlds/main/world.spec.json` — the editable WorldSpec (source of truth for the world)
- `design/game.spec.json` — GameSpec produced by the Design agent

The world is built at server start by `ServerScriptService/World/WorldBuilder`. Use `WorldForge → Bake to place` to persist it into the place file instead.
